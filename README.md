# Phicil-itate Change Oz Dashboard

A frontend-only React and Tailwind dashboard for reviewing healthcare experience
phone calls completed by Oz.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Useful Commands

```bash
npm run dev
npm run build
npm run lint
npm test
```

## Project Shape

- `app/page.tsx`: login/create-account screen and dashboard UI
- `app/layout.tsx`: page metadata
- `app/globals.css`: Tailwind and global styles
- `tests/rendered-html.test.mjs`: basic render checks
